# 无广告连点器 NoAdClicker

Clean-room Android auto clicker: multi-point taps, swipes, record & replay, loop by count/duration, JSON scripts.
No permissions, no network, no ads; the accessibility service only performs gestures and never reads screen content.

Build: `gradle :app:testDebugUnitTest :app:assembleRelease` (or push to `main`; GitHub Actions builds and publishes a release).
Spec: [SPEC.md](SPEC.md).
